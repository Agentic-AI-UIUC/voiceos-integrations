# Dropbox 2.0.11 live evidence and 2.0.14 release follow-up

The Windows VoiceOS run on November 10 loaded `dropbox-composio-v13-revision-pages`, version 2.0.11, and discovered 14 approved tools. The targeted live call `list_revisions({"path":"/VoiceOS Review QA 01/review.docx","limit":10})` completed with 10 entries, `has_more: true`, and no cursor. The result card says more revisions are available. This directly verifies the pagination regression reported by the preceding 2.0.10 run.

The earlier 2.0.10 Windows run exercised all 14 tools. Folder creation, Add and Overwrite uploads, copying, moving, revision restoration, link creation/listing/revocation, and deletion completed. Duplicate Add and Copy attempts returned conflicts without changing the existing destination. Repeating a successful Move returned unavailable because its source had already moved; that is not a destination-conflict test. Native confirmation cards showed Cancel and Confirm. Cancelled actions were absent from the supplied execution log. A prior Windows Preview test confirmed that an edited folder destination reached execution. The 2.0.11 change affects only revision response validation.

## Automated checks and remaining host QA

The 2.0.11 build and 88 local tests passed, including a clean portable MCP startup, 14-tool manifest parity, eight native confirmations, and regression cases for a revision page without a cursor and for other collections that still require a cursor. Both npm lockfiles match version 2.0.11. The installed Windows server, manifest, package, and cached VoiceOS record were verified at 2.0.11.

Version 2.0.13 additionally embeds the Composio OAuth2 Connect/Disconnect page in `server.ts --setup`; the source and portable page passed local smoke tests. The 92 offline tests also cover expired and revoked account feedback without dispatching a tool call. Version 2.0.12 was seen live with all 14 tools and a successful root listing; its unintended setup-page startup was fixed in 2.0.13 and covered by a normal-startup regression test. It has not had a fresh VoiceOS shared-install or full OAuth consent-cycle test. These screenshots are Windows evidence from 2.0.10 and 2.0.11. Native macOS VoiceOS behavior, live token expiry/revocation, and the host's outer response scrolling still need host QA. The Copy link control can fall back to selecting the URL for a system copy shortcut when clipboard access is unavailable. No live Mac claim is made from local cross-platform tests.
